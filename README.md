# NDKC ClinicCare

A modern and responsive user interface for the **NDKC ClinicCare** web-based School Clinic Management System. This project is designed to provide an intuitive experience for school nurses, administrators, students, and parents in managing clinic-related services at **Notre Dame of Kidapawan College (NDKC)**.

## Project Overview

### Concept

**NDKC ClinicCare** is a web-based School Clinic Management System developed for **Notre Dame of Kidapawan College (NDKC)**. It digitizes clinic operations by replacing traditional paper-based records with a centralized digital platform, enabling efficient management of student and personnel health records.

### Objectives

- Digitize student and personnel health records.
- Improve clinic visit documentation and monitoring.
- Streamline medicine and medical supply inventory management.
- Enhance communication between the school clinic, students, personnel, and parents.
- Generate reports to support data-driven decision-making.

### Features

- Student and Personnel Health Record Management
- Clinic Visit Recording
- Medicine and Medical Supply Inventory
- Medical Certificate Generation
- Parent Notification (Email/SMS)
- Analytics and Reports
- Role-Based Access Control
- User Account Management

### Technologies Used

- React
- Vite
- TypeScript / JavaScript
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- Framer Motion
- Lucide React

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm

### Installation

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
